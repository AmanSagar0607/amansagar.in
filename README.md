A personal portfolio starter for [amansagar.in](https://amansagar.in), built with Next.js, MDX, Tailwind CSS, and shadcn/ui.

This repository is designed to be used as a reference, a fork, or a starting point for your own portfolio. If you like the structure, feel free to reuse it and adapt it to your own brand, content, and workflow.

## README

- Portfolio site with blog, projects, experience, and contact sections
- MDX-powered writing and content pages
- Responsive navigation and section-based layout
- Reusable UI patterns for cards, lists, and content panels
- Built for easy customization and experimentation

## Use This

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Run the development server with `npm run dev`.
4. Update `src/app/page.tsx`, `src/content/posts`, and the shared components to match your own profile.
5. Replace links, images, metadata, and personal details with your own information.

## Contribute

## Local Development

```bash
npm install
npm run dev
```
