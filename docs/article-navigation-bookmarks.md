# Article navigation and bookmarks

- TOC rows now use the available card width, truncate long headings by default, and retain the existing expand control for long titles.
- LineNav markers and separators are shorter so labels have more room.
- Readers can bookmark the active section from the TOC popover or hover card. The bookmark is stored in browser local storage per article path and restores the saved heading when that same browser revisits the article.
- Bookmark storage is device/browser local. It does not require an account or send reading position to the server.
