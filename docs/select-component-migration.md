# shadcn Select migration

Replaced the previous native-select wrapper with the shadcn Select component generated by the shadcn CLI. Existing editor fields now render the Radix-backed Select, Trigger, Value, Content, and Item primitives.

Added a `FormSelect` compatibility field for the current editor definitions. It translates their option declarations into shadcn SelectItems and preserves the existing `onChange(event.target.value)` handlers while the forms are migrated incrementally.

## Verification

- `npm run typecheck` passed.
- `npm run lint` passed with four existing warnings (two image optimization warnings and two unused test-helper parameters).
- Tests were not run.
